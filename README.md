# Task Manager Application – Backend

## Project Description

A simple Task Manager backend application developed using Python, FastAPI and SQLite.

## Technologies Used

* Python
* FastAPI
* SQLite
* SQLAlchemy
* Pydantic
* Uvicorn

## Features

* Create new tasks
* View all tasks
* View tasks by ID
* Update existing tasks
* Delete tasks
* Mark tasks as completed
* Filter completed and pending tasks

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
uvicorn main:app --reload
```

## API Documentation

Open the following address in your browser:

http://127.0.0.1:8000/docs

## Database

SQLite is used to store task information.
